# Starsector 3D – Ship Models

Community-made 3D models for [Starsector 3D](https://github.com/winters791/starsector-3d). A ship with a model
here is drawn with it in 3D battles; every other ship keeps the relief Starsector 3D builds from its sprite.

## Install

1. Install Starsector 3D.
2. Download this mod's latest release, unzip it into Starsector's `mods` folder and enable
   **Starsector 3D - Ship Models** in the launcher.

To turn one ship's model off, delete its `data/meshes/hulls/<hullId>.obj` (and `.png`, if any).
